# OKGBI Auto - Система автоматизации производства ЖБИ

## Описание проекта

OKGBI Auto - это веб-приложение для автоматизации процессов производства железобетонных изделий (ЖБИ). Система позволяет управлять заказами, отслеживать производственные линии (треки), рассчитывать стоимость и сроки производства, а также интегрироваться с системой 1С для экспорта данных.

Основные возможности:
- Управление заказами и клиентами
- Отслеживание производственных линий и их загруженности
- Расчет стоимости производства
- Планирование производства с учетом сроков и мощностей
- Интеграция с 1С
- Статистика и отчеты по производству

## Установка и запуск

### Предварительные требования
- Docker и Docker Compose
- Git

### Шаги установки

1. Клонировать репозиторий:
   ```bash
   git clone <repository-url>
   cd okgbiAuto
   ```

2. Создать файл .env на основе .env.example:
   ```bash
   cp .env.example .env
   ```

3. Отредактировать файл .env, указав необходимые параметры:
   ```
   DJANGO_SUPERUSER_USERNAME=admin
   DJANGO_SUPERUSER_EMAIL=admin@example.com
   DJANGO_SUPERUSER_PASSWORD=secure_password
   DB_NAME=postgres
   DB_USER=postgres
   DB_PASSWORD=postgres
   BACKEND_URL=http://api:8000
   ```

4. Запустить приложение с помощью Docker Compose:
   ```bash
   docker-compose up -d
   ```

5. Приложение будет доступно по адресам:
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8002
   - База данных: localhost:54321

### Разработка

Для разработки можно использовать docker-compose.dev.yml:
```bash
docker-compose -f docker-compose.dev.yml up -d
```

## Структура проекта

### Backend (api/)
- **okgbi/** - основной проект Django
- **calculation/** - основное приложение для расчетов и управления производством
  - **models/** - модели данных (заказы, клиенты, треки, плиты и т.д.)
  - **services/** - бизнес-логика приложения
    - **calculator/** - логика расчетов
    - **export_1c.py** - экспорт данных в 1С
    - **manage_1c.py** - управление взаимодействием с 1С
    - **stats.py** - статистика и отчеты
  - **views.py** - представления API
  - **urls.py** - маршруты API
  - **tasks.py** - задачи Celery

### Frontend (frontend/)
- **src/components/** - React-компоненты
  - **Algorithm.js** - логика алгоритма расчетов
  - **CostParams.js** - параметры расчета стоимости
  - **Header.js** - шапка приложения
  - **Inventory.js** - управление инвентарем
  - **Orders.js** - управление заказами
  - **TrackAvailability.js** - доступность и планирование треков

## Использование

1. Войдите в систему, используя учетные данные администратора.
2. Создайте клиентов и заказы через интерфейс управления заказами.
3. Настройте параметры расчета стоимости.
4. Используйте интерфейс планирования треков для оптимизации производства.
5. Экспортируйте данные в 1С при необходимости.
